## 最终版本的新 demo 条件

最终训练只能使用 2026-08-03 之后按以下条件重新录制的数据：

- 机器人：Marvin A 臂，`192.168.14.190`。
- 控制：笛卡尔阻抗；策略频率 10 Hz；流式 IK/关节参考下发 200 Hz。
- 动作：5 维 `[dx, dy, dz, drz, gripper]`。
- 缩放：平移 `15 mm`，yaw `0.03 rad`，夹爪 `1.0`。
- 策略平移逐轴限制：`[-1, 1]`；底层旋转后使用模长保护，最大归一化平移模长为 `sqrt(3)`。
- 流式限制：平移速度 `60 mm/s`、平移加速度 `200 mm/s²`、yaw 速度 `20 deg/s`、yaw 加速度 `120 deg/s²`。
- 阻抗刚度 `K=[4000,6000,6000,600,600,600,20]`，阻尼 `D=[0.8,0.8,0.8,0.4,0.4,0.4,1.0]`。
- 最长 250 步；成功由分类器/脚踏板 wrapper 判定，不使用通用目标位姿提前终止。
- 策略图像：`side_policy`、`wrist_1`、`wrist_2`；分类器图像：`side_classifier`；均为 128×128。
- state 为 24 维，包含 pose、velocity、force、torque、gripper 和 `last_action`。

录制命令：

```bash
cd examples/experiments/marvin_usb_insertion
bash run_record_demos.sh 20
```

输出文件会写到 `examples/demo_data/`。新 demo 已由当前环境生成正确的 `last_action` 和奖励，训练时不要使用 `--migrate_legacy_data`。
录制程序还会生成 `<demo>.pkl.metadata.json`，其中保存本次真实控制条件；最终 learner 会在启动前同时校验 metadata 和 pickle 的动作、state、图像结构。

## 与最终训练的兼容规则

- 不混用 7 维动作、13/19 维 state 或 256×256 图像数据。
- 不加载旧训练目录里的 `buffer/` 或 `demo_buffer/`。
- 旧 RL checkpoint 只作为网络权重 warm start；新经验全部写入新的训练目录。
- 如果动作缩放、控制频率、流式速度/加速度、裁剪、EMA、图像裁剪或 state 定义再次改变，必须新建数据文件和训练目录，并更新本 README。
