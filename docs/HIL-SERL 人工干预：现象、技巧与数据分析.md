# HIL-SERL 人工干预实战指南：现象、技巧与数据分析

本文档总结 Marvin 光模块插拔任务训练过程中的人工干预经验，涵盖干预技巧、时机判断、异常行为处理及数据分析方法。

## 1. 干预前准备：操作者一致性

### 1.1 先练熟再采集

人工操作本身也需要一致性。在正式采集 demo 和开始训练之前，操作者应先练习 SpaceMouse 操控，确保能稳定、流畅地完成插入任务。


### 1.2 Demo 轨迹统一风格

**前期 demo（至少 20 条）建议采用统一的轨迹风格**，例如：
- 先抵达插座左侧附近 → 再右移插入

## 2. 干预时机判断

训练过程中干预策略应根据模型的学习阶段动态调整。

### 2.1 前期：纯探索阶段（每个回合都干预）

**现象**：模型刚开始训练，动作接近随机，完全不知道任务目标。

**策略**：每个 episode 都给予干预。
- 让模型自行探索 20-30 步，观察其行为
- 在模型明显偏离工作区域或做无意义动作时介入
- 将光模块引导到插座附近，让策略在"有希望成功"的区域探索
- 目标：让策略频繁获得成功奖励（原文要求至少 1/3 的 成功episode，我这边前期基本保持在2/3成功率），帮助 value 函数快速收敛

### 2.2 中期：选择性干预（模型学到部分技巧后）

**现象**：模型已掌握部分子技能（如夹爪推送），但其他子技能（如光模块对齐）尚未学会。

**策略**：分类干预。
- **已学会的部分**（如夹爪推送）：不干预，让模型自主完成
- **未学会的部分**（如光模块对齐）：允许模型自主探索几秒，若仍无进展再干预
- 核心原则：**边探索边纠正**，既给模型学习空间，又不让它浪费大量时间在无效行为上

**示例**：
```
模型已学会：夹住光模块推到插座附近
模型未学会：精确对齐插入
→ 夹爪推送阶段不干预，到达插座附近后观察 3-5 秒
→ 若模型对齐动作明显错误（如方向反了），再介入纠正
```

### 2.3 中后期：按模型风格干预

当成功率开始上升后，模型有自己的可以work的轨迹后，干预轨迹应**顺应模型当前的轨迹风格**，而非坚持 demo 的原始风格。

- 如果模型已经趋向于某种插入路径（如直接插入），就按照该最优路径干预
- 不要强行拉回 demo 风格的轨迹，这会造成策略困惑
- 逐步从"引导到左侧再右移"过渡到"直接插入"的最优轨迹

### 2.4 后期：几乎不干预

模型接近收敛后，仅在极端情况下干预（如掉落后重新抓取）。

## 3. 何时不干预

### 3.1 利用"异常行为"作为负样本

**现象**：本来稳定的模型，突然出现只朝一个方向移动的行为（如持续向某个方向偏移）。

**策略**：完全不干预，让该 episode 作为负样本。
- 这类负样本对策略学习"什么不该做"很有价值

### 3.2 模型在正确探索时

如果模型的探索行为在合理范围内（在工作区域附近尝试不同角度），即使效率不高也不要急于干预——让模型自主探索。

## 4. 不同行为模式及应对

### 4.1 已学会然后又忘了（遗忘/退化）

**现象**：策略之前能稳定完成某个子任务，但突然表现退步，反复失败。

**应对策略**：
1. **先不干预或少量干预**：将模型拉回工作区附近即可
2. **采集 2-3 个失败回合**：让模型在失败中积累负样本
3. **再探索 + 干预几个成功回合**：干预引导模型完成 2-3 个成功 episode，帮助策略重新建立"什么是对的"
4. **通常几个循环后就会恢复**

**核心逻辑**：
```
遗忘 → 采集负样本（认识到错了）→ 再采集正样本（记起对的）→ 恢复
```

### 4.2 从简单到复杂：渐进式任务难度

**策略**：不要一开始就要求完全插入。可以先降低成功标准，再逐步提高。

**操作步骤**：
1. **第一阶段**：固定初始位置，模型插入大部分就算成功"
2. **第二阶段**：策略学到一定程度后，逐步收紧成功标准
   - 要求更精确的对齐和更深的插入
3. **第三阶段**：放开初始位置随机化，训练完整插入能力


## 5. 干预训练的三个阶段总结

| 阶段 | 时长 | 干预频率 | 核心策略 |
|------|------|----------|----------|
| **前期** | 30 分钟 | 每回合干预 | 引导探索方向，让策略频繁获得成功奖励 |
| **中期** | 1-2 小时（最长） | 选择性干预 | 边探索边纠正，已学会的不干预，未学会的给几秒再干预 |
| **后期** | 30-60 分钟 | 几乎不干预 | 让策略自主完成，仅在失败情况介入 |


## 8. 关键原则总结

1. **一致性优先**：demo 和早期干预轨迹风格统一
2. **渐进放手**：从每回合干预 → 选择性干预 → 几乎不干预
3. **以模型为主**：中后期干预顺应模型当前的轨迹风格，不强行纠正到 demo 风格，任务能够work后再调整趋向最优
4. **负样本有价值**：稳定模型偶尔的异常行为不要干预，保留作为负样本
5. **遗忘可恢复**：遗忘了 → 采负样本 → 再采正样本 → 恢复
6. **难度渐进**：从简单（插入大部分即成功）到复杂（完全插入），逐步提高标准

## 9. 训练现象记录

### 9.1 技能学习顺序：从后往前学

模型学习子技能的顺序是从任务末端往前学的：

1. **先学会夹爪推送光模块**（最接近 reward 的动作）
2. **再学对齐**（精确调整位置和角度）
3. **最后学拿起夹爪**（episode 最前端的动作）

拿起夹爪虽然学得相对较快，但有时会出现遗忘。

**原因分析**：这与 discount factor（折扣因子）有关。在稀疏奖励设置下，越接近任务成功（episode 末端）的状态，其 value 估计中折扣衰减越少，奖励信号越明显。因此模型优先学会末端的技能，再逐步向前传导。

> 关于 200-length episode 下不同 discount 的对比分析，详见 [marvin_optical_module_training_guide.md](./marvin_optical_module_training_guide.md)。

### 9.2 后期模型超越人类轨迹

训练到后期，模型可能学习到比人工 demo 更优的轨迹：

- **现象**：demo 中人工习惯"先到左侧再右移插入"，但模型后期倾向于**直接插入**
- **说明**：RL 在充分探索后，发现了人工没有考虑到的最短路径
- **应对**：此时不要再干预纠正模型，这就是我们想要的结果——策略找到了比人更优的解

### 9.3 学习难度

训练中观察到，不同随机化维度对学习难度的影响差异很大，从易到难：

| 难度 | 条件 | 说明 |
|------|------|------|
| ★ 最易 | 固定初始位置 | 复位位姿不变，模型只需学固定起点的轨迹 |
| ★★ | 初始位置左右移动 | X 方向偏移，夹爪抓取姿态基本不变 |
| ★★★ | 初始位置前后移动 | Y 方向偏移，导致夹爪与光模块相对位姿不同 |
| ★★★★ 最难 | 光模块被碰偏 | 运动中被碰撞导致角度偏移，模型会尝试纠正角度，但这种情况本身就很难插入 |

> 增加随机化维度时，建议逐级递进，先在固定条件下学到基本策略，再逐步放开。

### 9.4 异常情况处理

**场景**：光模块被碰偏、插入到下方卡槽等异常位置。

#### 方案 A：示教"放下重新抓取"

- 当光模块位姿不好时，干预让夹爪放下光模块，再重新抓取
- **问题**：尝试了几条这种数据后，夹爪反而不知道什么时候该打开、什么时候该闭合，夹爪控制能力变弱
- **原因**：此类样本太少，模型无法从有限数据中归纳出"何时释放夹爪"的判断条件；"放下重抓"引入了更复杂的状态空间（已抓取/未抓取/已放下）

#### 方案 B：人手控制恢复初始状态（推荐）

- 直接上手把光模块放回正确位置并重新抓取，相当于手动重置环境
- **效果**：成功率较高
- **原因**：避免引入复杂的"释放-重新抓取"子任务，保持任务流程简洁
- **代价**：需要人一直在旁边看着

## 10. 优化方案

针对当前训练中观察到的现象和问题，提出以下优化方向。

### 10.1 增大 discount factor（折扣因子）

**问题**：当前模型从后往前学（先学末端推送再学前期抓取），早期动作的奖励信号在长 episode 中经过多步折扣衰减后几乎消失。

**方案**：增大 discount factor γ（如从 0.97 提升到 0.99 或更高），减少折扣衰减速度，让 episode 前端的动作也能获得有意义的 value 信号。

**预期效果**：
- 前端的"拿起夹爪"等早期技能学习更快
- 减少"遗忘"现象——早期动作的价值估计更稳定

> 关于 200-length episode 下不同 discount 的对比分析，详见 [marvin_optical_module_training_guide.md](./marvin_optical_module_training_guide.md)。

### 10.2 使用 HER + SAC

**问题**：当前使用 DRQ（DrQ-v2）算法，稀疏奖励下早期动作的奖励信号传导效率仍然有限。

**方案**：引入 HER（Hindsight Experience Replay）+ SAC（Soft Actor-Critic）组合。

**原理**：
- HER 将失败的 episode 中实际到达的末端状态作为"虚拟目标"，重新标记为成功（sparse → dense-like），让模型从每一个 episode 中都能学到有用的行为——即使该 episode 最终没有达到原始目标
- SAC 的最大熵框架天然鼓励探索，有助于覆盖更广的状态空间

**预期效果**：
- 早期动作学习加速——HER 让"夹爪抓取光模块"这类未成功 episode 中的正确子动作也能获得正反馈
- 减少对人工干预的依赖

### 10.3 减少 replay buffer 中"过渡样本"

**问题**：训练早期为了提升成功率，分类器放宽了"成功"判定标准（如插入一半即判定成功）。这些"半成功"样本留在 replay buffer 中，会持续影响策略对"什么是成功"的认知，导致策略止步于半插入状态。

**方案**：
- 减小 replay buffer 容量，加快旧样本的替换速度
- 或者：在收紧分类器标准后，清空 buffer 重新采集（即训练中期做一次 buffer 冷启动）
- 或者：对 buffer 中的旧样本按分类器版本标记，训练时降低旧标准样本的采样权重

**预期效果**：
- 策略更快摆脱"半插入就满足"的行为模式
- 最终插入深度和成功率提升

### 10.4 增大动作跳变惩罚

**问题**：当前策略输出的动作仍然有些抖——相邻 step 之间动作变化不够平滑，在实际机器人上表现为末端抖动。

**方案**：在 reward 函数中增加动作平滑性惩罚项。

### 10.5 优化图像裁减ROI区域

**问题**：128*128训练速度快但是比较模糊，256*256图像清晰但是训练速度有些慢

**方案**：划定ROI标准：尽量只保留关键区域小一点，这样128*128也能清楚
